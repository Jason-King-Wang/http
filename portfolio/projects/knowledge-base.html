Architecture

  • characters 記錄角色當前設定、身份、能力、外觀與提示詞線索。
  • experiences 記錄角色在故事中的事件與來源章節，不把經歷塞爆設定檔。
  • indexes 整理人物關係、圖像索引、來源索引與候選人物。
  • translations 管理英文版譯名與關係邊，新增角色會標記 needs_review。
  • conflicts 保存來源矛盾，避免 AI 自行覆蓋使用者腦中的設定。

Done

  • 建立角色圖設計指南、圖像 reference 優先級、角色卡 / 形象圖 / 大頭照分支規則。
  • 建立 Obsidian export workflow，把人物、關係、經歷、來源索引輸出成 wiki-link 網路。
  • 建立英文譯名表同步與 relationship edges。
  • 建立矛盾處理規則：不急著刪舊設定，而是標記命運線或待確認。

Remaining Work

  • 把向量搜尋 API 接到展示網站，維持 localhost、安全白名單與摘要回傳。
  • 建立 automated source ingestion，避免手動維護 markdown index 過重。
  • 做 prompt regression：同角色多次生成時檢查臉、髮型、氣質是否漂移。
