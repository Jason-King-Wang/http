Luna Agent Workflow

A reusable Codex workflow for delegating bounded work while keeping planning, acceptance and integration with the parent agent.

  • Codex skills
  • Task design
  • Agent roles
  • Acceptance
  • Failure review

A complete task before a worker starts

I designed this workflow around a simple requirement: a worker should receive enough information to complete one bounded task without inheriting an entire conversation or guessing the missing decisions.

The parent agent first chooses the direction, resolves dependencies and defines the outcome. Each new worker receives a self-contained task packet with exact inputs, fixed decisions, scope limits, expected outputs and a proportionate verification method.

From delegation to acceptance

  1. Prepare the task packet. Check that the goal, input locations, permitted work and pass conditions are clear.
  2. Start a bounded worker. Use the designated worker configuration and verify the available runtime metadata. Only independent work should run in parallel.
  3. Review the result. Treat the worker's report as evidence to check. The parent agent independently assesses the original goal, boundaries and integration needs.
  4. Revise before retrying. If the result is blocked or fails acceptance, identify the cause and give a fresh worker a complete, revised task packet.

Failure review with a specific next step

The review distinguishes task-specification problems, task–model mismatch, execution defects, environment blockers and parent-agent integration problems. This makes the next action more specific than asking the same worker to “try harder.”

Only recurring structural gaps become candidates for improving the general skill. Task-specific details stay with the task.

A second-opinion extension

The companion ask-web-pro skill defines a browser-based relay for a second opinion. It checks the selected web model and mode, preserves the question, waits for the complete response and returns the response and conversation URL. The parent agent reviews that advice against local evidence before acting.
