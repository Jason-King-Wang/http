整合方式

這個入口站怎麼運作

  • 首頁會讀取共用 manifest，顯示兩套系統的最新摘要。
  • 賣價模型頁與自動交易頁各自保留原內容，但共用同一套導覽外殼。
  • 同步腳本會重建嵌入內容，之後就能再往外部靜態網站部署。

這是一個 external-ready 的站台骨架。等接上 git repo 與 GitHub Pages 之類的託管目標後，才會真正變成公開網址。
