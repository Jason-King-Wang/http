Architecture

  • 資料層讀取 1H / 15m OHLCV，若只有 15m 可 resample 成 1H。
  • market_structure 模組識別 confirmed swings、price-based centers、a/b、b-A。
  • strategy state machine 防止 lookahead bias，所有拒絕理由以 reason_code 記錄。
  • execution profile 拆成 tw_round_lot / tw_odd_lot，考慮滑價、手續費、交易稅、T+2、漲跌停、成交量限制。
  • output 產出 signal_log、trade_log、performance_report 與 annotated_chart.svg。

Done

  • 將人讀規則整理為 RULES.md，明確第一部影片為交易規則主體，第二部只作概念輔助。
  • 建立 Python package、CLI、config、data loader、state machine、execution simulator。
  • 建立 unit tests 覆蓋 swing、center、MACD diagnostic、strategy rules、台股 execution。
  • 跑完全資料 tw_round_lot 回測：1957 檔、1173 筆交易、總 PnL -1,049,331。

Remaining Work
