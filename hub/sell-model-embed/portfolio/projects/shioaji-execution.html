Architecture

  • SelectionProvider 只讀標準化上游輸出，不知道私有選股規則。
  • Finalizer 用目標日期與 10:00 materialization gate 防止 stale file 被鎖成正式買單。
  • Sizing 以 weekly budget / hard budget / approved snapshot 建立可審計下單數量。
  • BrokerAdapter 分離 fake broker 與 Shioaji broker；live 需環境旗標、config、CLI confirm、帳戶驗證全通過。
  • Repair confirmation 在 partial failure 後先對帳，再只允許未送出的 remainder。
