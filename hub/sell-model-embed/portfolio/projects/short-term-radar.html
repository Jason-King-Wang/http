Architecture

  • slot-based design：PRICE、UNIVERSE、REVENUE、CHIP、SURVEILLANCE、CATALYST、CORPORATE、FINANCIAL、VALUATION、CALENDAR。
  • collect CLI 支援 official dry-run、small-range live write、normalize、validate 與 degraded no-empty-write。
  • source_verification 要求兩個獨立來源一致才寫入 crawled values。
  • financial backfill runner 有 allowed-root、status JSON、event log、lock、stop file、blocked/degraded cooldown、symbol quarantine。
  • diagnose / heal CLI 讓 automation 先判斷 should_run，再決定是否發 network requests。

Done

  • 接入 MOPS monthly revenue、financial statement income/balance、TWSE/TPEx institutional trading、margin/short 等官方來源。
  • 建立 Yahoo / Cnyes / MoneyDJ / Goodinfo public revenue verification，並分類 login_required、js_cookie_required、access_limited。
  • 建立 coverage / freshness / missing-date reports，避免 partial slot 被誤判成 full mode。
  • 建立 financial backfill 的診斷與自我修復流程，避免 scheduled automation 一直打爆來源。

Remaining Work

  • 完整回補 institutional trading、margin/short、surveillance、valuation 等歷史資料。
  • 把 source health 變成固定 dashboard，而不是只看 quality CSV。
  • 補 RAG/LLM fallback 只處理低信心文件抽取，且不得直接寫 processed rows。
