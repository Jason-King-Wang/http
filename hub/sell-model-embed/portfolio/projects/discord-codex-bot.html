Discord Private AI Bot 與本機 Codex Bridge

一個只回應核准 Discord 使用者與私人頻道的 AI bot。它能把 Discord 訊息安全轉交本機 Codex CLI，保留 channel-level session、附件接收、檔案傳回、transcript 使用量提示與 Windows service mode。

Architecture

  • ALLOWED_USER_IDS / ALLOWED_CHANNEL_IDS / ALLOW_DMS 控制誰能觸發 bot。
  • CODEX_HANDLE_ALL_MESSAGES / CODEX_TRIGGER_ONLY 控制是否所有訊息都轉給本機 Codex。
  • per-channel session store 讓不同 Discord channel 對應不同 Codex thread。
  • 附件下載限制在 CODEX_WORKDIR，且檢查 CDN URL、大小、extension 與敏感 path keyword。
  • 檔案傳回也需要 allowed roots、extension allowlist、max bytes 與 secret path block。

Done

  • 完成 Discord bot、OpenAI fallback、本機 Codex courier mode、channel session 與 Windows service scripts。
  • 建立 transcript memory 與刪除確認機制，不把刪除語意直接執行成清空記憶。
  • 建立 attachment receive / send allowlist，避免任意路徑讀寫或外洩。
  • 建立 insufficient_quota fallback 邏輯，可改走本機 Codex。

Remaining Work

  • 增加 end-to-end integration tests，尤其是附件下載、檔案傳回與 thread reset。
  • 補更完整的 observability dashboard：queue length、last success、last failure、session size。
  • 若要產品化，需要改成多租戶權限模型與明確 audit log。
