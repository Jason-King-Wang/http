FAQ

常見問題

用清楚、低壓的說法回答常見的產品定位與使用邊界。

這是券商 App 嗎？

不是。本系統是交易規則量化與下單輔助工具，協助使用者整理規則、檢查流程與遠端操作交易系統。

系統會推薦股票嗎？

不會。系統依使用者設定的條件顯示符合規則的結果，不提供個股投資建議。

是否接券商 API？

產品設計方向包含券商 API 安裝精靈，協助使用者整理 API Key、CA 憑證與模擬 / 實盤流程。

手機端可以做什麼？

手機端可查看策略狀態、接收提醒、切換模擬 / 實盤、查看可用資金，並以預算下單方式輔助使用者送出委託。
