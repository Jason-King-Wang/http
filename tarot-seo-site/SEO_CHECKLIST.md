# SEO 上線檢查清單

## 每次新增頁面

- [ ] 頁面只處理一個清楚的搜尋意圖。
- [ ] 使用獨立且自然的標題與描述，避免只替換關鍵字。
- [ ] 設定唯一 canonical URL。
- [ ] 首頁或相關內容有連結可以到達新頁面。
- [ ] 新頁面已納入 `sitemap.xml`。
- [ ] 圖片具有符合內容的替代文字，尺寸與檔案大小合理。
- [ ] 內容經人工檢查，不做無差異的大量生成。
- [ ] 醫療、心理、法律、財務等內容包含清楚使用邊界。

## 每次大改版

- [ ] 先執行 `ADS_SETUP.md` 的大改版模式。
- [ ] 既有網址若能保留就不要更換。
- [ ] 必須更換網址時建立永久重新導向，避免大量 404。
- [ ] 手機版選單、主要按鈕與文字可正常操作。
- [ ] 檢查首頁、所有牌陣、所有指南及政策頁。
- [ ] 檢查 `robots.txt`、`sitemap.xml` 與 canonical 網址仍指向正式網域。
- [ ] 檢查結構化資料沒有使用錯誤或過期內容。
- [ ] 發布後透過 Search Console 觀察索引與錯誤。

## 換正式網域

- [ ] 先完成新網域 DNS 與 HTTPS。
- [ ] 更新 Sites 的 `SITE_URL`。
- [ ] 更新 Search Console 網站資源並重新提交 sitemap。
- [ ] 在 AdSense 新增新網域並等候審查。
- [ ] 舊網址保留重新導向，避免搜尋排名與既有連結失效。

## 每月維護

- [ ] 檢查 Search Console 的索引、點擊、查詢與頁面體驗。
- [ ] 修復失效連結與 404。
- [ ] 更新日期只在內容實際修訂時變更。
- [ ] 檢查廣告是否靠近互動按鈕或遮擋內容。
- [ ] 記錄重要修改到 `CHANGELOG.md`。
