    Explicit calculation

    Normalize benefit, readiness, cost, risk and quality from 0–100 into u, m, c, r and q. Age t is measured in days.

    U = (1 − exp(−k·u)) / (1 − exp(−k))
D = exp(−ln(2)·t/H)
P = exp(−beta·r²)
Z = w_u + w_m + w_c + gamma
B = (w_u·U + w_m·m + w_c·(1−c)
     + gamma·U·m) / Z
S = 100 · B · D · P · q

    Validate inputs and policy before checking eligibility. k: 0.1–10; H: 0.25–365 days; other parameters: finite, non-negative; Z must be finite and positive. The first five inputs are 0–100; age is 0–365 days.

    Rules-to-code collaboration

    My role is to define needs, rules and acceptance criteria, guide AI-assisted implementation and revisions, and review behavior. AI assists in creating code, tests and documentation; it does not make runtime scoring decisions.

    This independent public demo uses separately constructed rules, parameters and illustrative cases. It excludes private original model details and data.

    No model training, calibrated success probabilities, demonstrated predictive accuracy or production deployment is claimed.
